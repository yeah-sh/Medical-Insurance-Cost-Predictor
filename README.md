
# Medical Insurance Cost Predictor

## Overview
A machine learning project that predicts medical insurance charges based on personal and lifestyle information.

## Planned Features
- Explore and visualize the insurance dataset
- Preprocess data for machine learning
- Train regression models
- Evaluate model performance
- Build a prediction interface using Streamlit

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

## Project Status
In development.
